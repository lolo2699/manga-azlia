# Manga Azlia | مانجا أزليا

مشروع Full-stack تأسيسي قابل للتشغيل محليًا باستخدام Node.js وExpress وSQLite.

## التشغيل
1. ثبّت Node.js 18 أو أحدث.
2. انسخ `.env.example` إلى `.env`.
3. ضع قيمة طويلة وعشوائية في `SESSION_SECRET`، واختر بنفسك كلمة مرور قوية في `ADMIN_PASSWORD`.
4. نفّذ `npm install` ثم `npm start`.
5. افتح `http://localhost:3000` وسجّل الدخول باسم المسؤول `ashealen3` وكلمة المرور التي أدخلتها في `.env`.

لا ترفع `.env` إلى Git ولا تضع كلمة المرور في HTML أو JavaScript. يتم إنشاء المسؤول وتحديث كلمة مروره من الخادم عند بدء التشغيل.

## الموجود في هذه النسخة
واجهة عربية متجاوبة، بحث، حسابات وتسجيل دخول، صلاحيات مسؤول على الخادم، إضافة أعمال وأغلفة، رفع فصول متعددة الصور، قارئ فصول، مفضلة، وإحصائيات أساسية.

## قبل النشر للجمهور
هذه نسخة تأسيسية وليست منصة إنتاجية مكتملة. يلزم إضافة حماية CSRF وتحديد محاولات الدخول وفحص محتوى الملفات المرفوعة، وإكمال تعديل الفصول وإدارة المستخدمين والإشعارات والبنرات والنسخ الاحتياطي، ثم نشرها خلف HTTPS مع تخزين دائم. انشر فقط الأعمال التي تملك حق استخدامها أو إذنًا بنشرها.
